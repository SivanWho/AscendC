# Concat 官方输入契约回归测试报告

- 时间：2026-07-30
- 目标设备：Ascend 910B（远端比赛环境）
- 调用方式：测试专用的单次 `aclnnConcat` 桥接；与官方示例一致的 ACLNN ABI。
- 判定：CPU `torch.cat` 参考结果与 NPU 输出逐元素完全相等（`torch.equal`）。
- 结果：**1000 / 1000 通过**，累计验证 `43,357,777` B，执行耗时 `12.3 s`。
