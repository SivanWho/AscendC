# S9 官方材料

- `S9-problems.zip`：官方 S9 题包。
- `S9-problems/`：题包解压内容，含 `S9挑战性能赛题.xlsx` 和五题公开调用样例。

题包来源：[S9 官方页面](https://www.hiascend.com/developer/contests/details/41ffbad2024e4ccfa43520c57ffa7b9e?channelCode=S22)。
